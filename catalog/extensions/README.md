⚠️ **研究基线：不是764个已验证独立图型。** 630+134=764只是去除完全匹配名称后的候选计数。新候选仅12个有直接名称证据，其余143个只有领域级来源，仍需逐项核对、同义词合并与HTML实现测试。

`status` 表示相对旧目录的完全匹配结果；`evidence_level` 表示来源直接性，不等于专业正确性。可视化风格、材质、相机投影与动画必须独立于独立图型名称。
