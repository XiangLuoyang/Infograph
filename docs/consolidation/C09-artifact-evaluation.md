# C09-E2 Artifact evaluation
Install Playwright in a local environment and install Chromium. Run node evaluate-artifacts.mjs benchmark-local benchmark-review only in a disposable isolated environment without secrets or network access. Generated HTML is untrusted executable code; browser routing is not a complete security boundary. Initial render checks at 1440 and 390 pixels record errors, attempted requests, document overflow, text and element counts, screenshots. No automatic factual verification, interaction exercise, flow geometry or blind anonymization yet. Screenshots use run IDs, not blinded IDs. Review evaluation-checks.json against answer-key.json separately. No real artifacts or browser tests executed. The script may hang on malicious or nonterminating JavaScript; use external process timeout and isolation. Do not treat observed-pass as release approval.
