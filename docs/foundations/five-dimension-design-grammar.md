# 🎨 可视化看板五维设计语言与布局语法

> [!abstract]
> **看板不是把数据和图表摆得好看，而是将信息关系翻译为空间、形状、质感、颜色与时间变化。** 以 Information Intent 为上游，将 Color / Layout / Material / Chart / Interaction 五维作为可组合的设计语法，最后通过视觉、认知、业务和交互测试验证。本文记录 2026-11-18 的框架讨论与研究方向，属于可演进的**方法论提案**，不是已经验证的通用设计标准。

## 一、核心命题：先有语义，再选表现

- **What：信息是什么**——指标类型、维度、粒度、单位、时间、因果/关联边界。
- **Why：要让谁理解什么**——排名、偏差、趋势、结构、关联、流向、层级、地理空间、成因、决策。
- **How：以何种方式表达**——布局、图表、颜色、材质、交互及转场。
- **Verify：表达是否成立**——准确率、理解速度、错误率、可读性、联动正确性及审美一致性。

核心思路与 Tamara Munzner 的 *Visualization Analysis and Design* 的 Why/What/How 任务—数据—编码框架相互呼应；本页的五维和后述五类布局是我们的**自定义工作分类**，不宣称学界存在相同的统一分类法。

> [!important] 设计原则
> 布局不是一个装载图表的容器系统；布局通过距离、对齐、比例、方向、嵌套和留白，**直接表达信息之间的关系**。不能先想“用12列卡片”，再把信息填进去；应该先识别对象及其关系，再生成空间结构。

## 二、五维设计语言：各自承担什么任务

| 维度 | 设计问题 | 核心变量 | 典型反模式 |
|:---|:---|:---|:---|
| Color / 配色 | 什么是重要、同类、异常，气质是什么？ | 语义色、序数/发散色阶、对比度、明度与饱和度 | 仅按审美上色，混淆同类和风险 |
| Layout / 排版布局 | 信息为何相邻、谁主谁次、如何阅读？ | 分组、对齐、栅格、比例、密度、留白、顺序、层级 | 全部等面积卡片，没有视觉重点 |
| Material / 材质 | 信息具有何种视觉角色与空间层次？ | 纸张、玻璃、金属、哑光、边框、阴影、纹理、折射 | 高密度图表上添加干扰读数的纹理 |
| Chart / 图表 | 数据关系应通过何种视觉编码显现？ | 位置、长度、面积、角度、颜色、连线、地图 | 默认使用炫技图，牺牲数量精度 |
| Interaction / 交互动画 | 用户怎样发现、探索和理解变化？ | 选择、筛选、钻取、联动、展开、转场、时间轴、模拟 | 动画只为炫酷，不保留状态或上下文 |

这里的「视觉气质/材质联想」属于设计判断，不是可普遍复现的心理学效应；应用前必须按场景验证。

## 三、Layout Grammar：从排列到信息关系

### 1. 支撑性理论

- **格式塔原则**：接近、相似、共同区域、连续性等影响观者如何自动分组。
- **视觉层级**：大小、位置、留白、对比与文字层次决定读者先注意什么。
- **栅格与基线系统**：一致的几何约束保证节奏、比例和对齐；栅格是约束，不是所有页面必须长得相同的模板。
- **认知负荷与渐进披露**：高管一次性汇报侧重结论与证据；长期分析工作台允许逐层进入细节。

### 2. 五类布局原型（工作分类）

| 原型 | 信息关系 | 适用案例 | 优先考虑的视觉结构 |
|:---|:---|:---|:---|
| Matrix 矩阵 | 并列、对比、监控 | 多国多指标经营监控 | 等比例网格、对齐、统一量尺 |
| Editorial 编辑 | 论点—证据—决策 | 向高层汇报泰国库存问题 | 结论标题→主证据→旁栏解读→行动 |
| Hierarchical 层级 | 总体—分部—细节 | 国家→渠道→代理商→门店 | 空间嵌套、树、递进展开 |
| Flow 流程 | 先后、路径、价值传导 | 进货→动销→库存形成 | 连续方向、可追踪路径、条件关系 |
| Spatial 空间 | 地理、网络、物理关系 | 东南亚3D经营地图 | 地理形状、空间位置、焦点切换 |

**布局选择规则**：优先识别主要关系；一屏只确立一个主叙事方向；次要信息可借助辅助布局（如 Editorial 主视觉内嵌 Matrix 小图）。如果仅仅换成不对称卡片，但没有改善理解，则不算语义驱动的布局。

### 3. 视觉层级实验

同一组指标分别制作 A 版「所有KPI平权的均匀网格」与 B 版「结论→KPI证据→主图→决策」；用相同数据和读者任务测试：
- 5秒后能否说出页面主问题；
- 30秒内能否找出库存异常和行动建议；
- 数字核验错误率、图表阅读负担与主观审美评分。

> [!caution] 研究边界
> B版对一次性决策汇报可能更优，A版对持续监控可能更优；**不把某一布局的偏好当成普适优越性**。

## 四、Material Grammar：材质是一种界面语义

| 材质语言 | 可能产生的视觉联想（设计假设） | 候选场景 | 需要约束 |
|:---|:---|:---|:---|
| 羊皮纸/旧档案 | 历史、溯源、制度、时间沉淀 | 历史经营沿革、制度复盘 | 纹理不得压低文字与图表对比度 |
| 哑光纸张/印刷 | 理性、编辑感、证据 | 经营汇报、财务与研究报告 | 不要模拟无意义的纸纹 |
| 半透明玻璃 | 轻盈、分层、当下聚焦 | 地图选择浮层、导航覆盖层 | 背景模糊需保证信息可读 |
| 金属/精密仪表 | 工业、耐用、专业设备 | 生产/设备运行控制 | 拒绝无意义的仪表盘装饰 |
| 地形/实体块面 | 空间尺度、真实物理关系 | 3D国家地图、渠道覆盖 | 不以透视大小替代精确数值比较 |
| 技术线框 | 系统、拓扑、结构关系 | 网络/机制/依赖关系 | 线路密度与拓扑正确性优先 |

东南亚经营地图的建议分层：**底层**哑光地理空间，**国家实体**分层几何，**当前选择**高亮，**辅助信息**玻璃浮层，**风险/异常**实色标签；材质之间的差异应服务功能，不是整页换肤。关联 [综合-东南亚3D地图本体六种渲染语言实验](../research/map-rendering-languages.md)。

## 五、Chart Grammar：先判任务，再选编码

| 认知任务 | 候选图表 | 避免的误用 |
|:---|:---|:---|
| 排名比较 | 排序水平条形图、点图 | 无排序的彩色3D图 |
| 目标偏差 | 发散条形图、Bullet | 只给完成率不提供基准 |
| 时间变化 | 折线图、Small Multiples | 无必要的3D面积 |
| 组成结构 | 堆叠条形图、矩形树图 | 类别过多的饼图 |
| 分布形态 | 直方图、箱线图 | 均值掩盖长尾 |
| 相关关系 | 散点图、气泡图 | 把相关直接宣称因果 |
| 量级比较 | 条形图/点图 | 用面积或透视误导精确量值 |
| 地理关系 | 符号地图、分级设色、3D地图 | 用地图承担精确数值排名 |
| 资金/货物流 | Sankey、Alluvial | 未核验流量守恒的流向图 |

依据：Cleveland & McGill（1984）关于视觉编码比较精度的研究、FT Visual Vocabulary 对图形按任务分类的实践。**精确值比较优先考虑共同量尺的位置与长度**；具体编码仍须结合数据量、业务背景、样本、可访问性及视觉任务。

示例：同样的四国完成率，**排序条形图**强调国家名次；以100%为基准的**偏差图**强调超额/未达标；不要因为数据相同就认为图表必须相同。

## 六、Interaction Grammar：信息沿什么路径显现

| 用户任务 | 交互方式 | 动画的认知职责 |
|:---|:---|:---|
| 发现异常 | 悬停、局部高亮、告警过滤 | 指向重点 |
| 展开层级 | 点击钻取、展开/折叠 | 维持当前对象与父级关系 |
| 比较两个对象 | 联动选择、并排、同步高亮 | 明确元素映射 |
| 理解趋势变化 | 时间滑块、时间播放 | 显示真实时间顺序 |
| 理解形成过程 | 分步揭示、滚动叙事 | 标明证据步骤与前后关系 |
| 探索空间 | 缩放、旋转、聚焦、定位 | 保持方向与空间上下文 |
| 评估方案 | 输入参数、情景切换、即时重算 | 明示假设→结果的变化 |
| 追溯证据 | 明细展开、来源跳转 | 可核验，而非仅制造确定感 |

参考 Shneiderman（1996）的 Overview first → Zoom and filter → Details on demand，以及 Heer & Robertson（2007）对图表过渡与对象恒常性的研究。

约束：
1. 用户不操作时仍能看到主要结论，Hover 不承载唯一关键证据；
2. 动画让同一对象在状态变化中可追踪，而不是固定要求全部元素飞入；
3. 尊重 reduced motion；需要时直接切换而不是强制动画；
4. 时间序列动画不得暗示未经验证的因果关系；
5. 任何模拟都区分**事实数据、推导值、情景假设**。

### 东南亚经营地图的五步示例

总览 → 点击泰国（高亮+引线+经营卡）→ 点 WOS（产品结构钻取）→ 时间轴呈现库存形成 → 调整补货与动销参数进行情景计算。

这五步是交互设计路径，**不意味着当前HTML已经实现全部联动或完成经营模型验证**。真实交互以代码和验收结果为准。

## 七、设计语法的生成与验收流水线

```text
业务问题 / 受众 / 数据口径
          ↓
Information Intent（目标认知任务）
          ↓
信息关系图（对象/证据/层级/时间/空间）
          ↓
候选 Layout + Chart + Interaction
          ↔
Color + Material + Typography Tokens
          ↓
原型实现 / 真实截图 / 交互测试
          ↓
业务口径验证 + 阅读任务验证 + 视觉 QA
          ↓
可复用规则、反例与黄金样例入库
```

建议建立三类知识资产：
1. **设计规则库**：信息关系→布局/图表/交互选择条件、约束与反例；
2. **视觉语言库**：配色、材质、字体、线条、空间、光影、动效 Tokens；
3. **设计案例库**：同数据不同方案，说明为何有效、如何评估、适用边界。

候选验收项：事实口径正确、关键结论无需悬停、视觉层级清晰、图型编码契合任务、材质不妨碍读数、交互保留上下文、动画尊重减弱动态效果、投屏/桌面可读、数据权限合规。验收框架与 [工具-企业经营治理HTML看板生成与验收](../engineering/html-dashboard-generation-qa.md) 对齐。

## 八、研究路线与尚待验证

**优先研究顺序（建议，不是强制规范）**：
1. Layout Grammar——对象/关系到空间构图，建立五类原型对照实验；
2. Interaction Grammar——目标认知任务到交互状态机与动效的映射；
3. Chart Grammar——结合任务、数据与编码精度的图表推荐器；
4. Material + Color——材质角色、语义色、情绪与品牌一致性。
5. 最后构建设计评估闭环——静态截图、可访问性、自动布局检查与真实用户的任务正确率。

**开放问题**：如何用结构化中间表示表达「视觉叙事意图」，让模型编排信息布局，而不只是往卡片容器里填组件？如何客观验证一套布局相较另一套布局提高了理解效率？

## 九、2026-11-22 范围修订：Chart 不等于统计图表

> [!important] 五维方法论保留，图型本体向全领域扩展
> 之前 Chart Grammar 的示例主要属于统计任务选图，其边界不能代表完整的图形语言。后续 Chart / Visual Representation 应同时支持工程爆炸图、剖面图、装配图、科学体可视化、网络拓扑、BPMN、P&ID、星图等专业表达，并与2D/3D、材质、交互、渲染引擎做独立建模。

- 先确认 **Information Intent + Domain**，再选专业图型和基础编码；最后组合投影/材质/交互/HTML实现。
- FT Visual Vocabulary 只能支撑统计图型选型，不是跨学科图型的全集。
- 依据 [综合-全领域可视化图表库覆盖审计与分类体系](../research/full-spectrum-breadth-audit.md) 的广度审计，当前24分类/630命名项仍有明显领域缺口，暂不宣称全量 Skill 或组件已经具备。
