# 🗺️ 六种地图本体渲染语言实验

> [!abstract]
> **地图风格 ≠ Dashboard UI Skin。** 地图本身的外轮廓、边界线、材质纹理、深度、透明度、信息图层和交互动画才是本轮实验对象。保留相同的页面框架、国别对象、经营数据和信息卡，分别渲染六种不同地图几何语言，便于纯粹比较地图本体的视觉和交互差异。这是 [综合-东南亚3D地图六风格评估与融合方案](map-six-style-evaluation.md) 后续一次**新的需求纠偏与独立原型**，不是简单替换旧HTML的主题色。

> [!info] 可运行资产与数据边界
> **当前交付版（V0.2）已推送**：[sea_3d_six_map_material_renderings_v02.html](../../examples/geospatial/sea_3d_six_map_material_renderings_v02.html)，这是2026-11-08在会话中给用户展示并供下载的那份独立HTML源码（与会话文件逐字一致）。**前一份归档版保留**：sea_3d_six_map_material_renderings.html，路径 `知识库/综合/可视化示例/东南亚3D经营机制沙盘/sea_3d_six_map_material_renderings.html`。这是完整单文件、离线可运行HTML，国家边界为简化几何；人口、GDP、销售额、目标、铺货、上样、WOS均为合成样例。**卫星与地形质感由程序生成示意纹理，不是真实卫星瓦片或DEM高程数据。** 这里的3D是Canvas投影的国家几何挤出，并非具备地形高程的GIS实景引擎。

## 一、纠偏对象

此前 [综合-东南亚3D地图六风格评估与融合方案](map-six-style-evaluation.md) 中的六款，虽然交互机制有不同，但大量差异仍来自**整页背景、KPI卡、侧栏和配色**。用户明确指出需要重点比较地图本体：
- 国家边界线的粗细、描边、虚实、栅格与海岸线处理；
- 地图表面的卫星/地貌/杂志/卡通/玻璃/工程线框材质；
- 顶面与侧壁的透明度、高度、层叠和视觉空间感；
- 国家被选中后的地图级交互动画，而不是页面换肤。

因此，本轮固定外围UI和经营样例数据，以**材质与渲染算法**作为唯一主变化维度。

## 二、六套本体绘制方法

| # | 地图本体 | 实现的材料/结构差异 | 专属地图交互 | 适用展示 |
|:---|:---|:---|:---|:---|
| 01 | **卫星沙盘 / Satellite-inspired** | 独立的程序化植被、地貌、聚落色彩纹理投射至国家顶面；侧面暗色实心 | 选中地块的高光扫过、镜头聚焦 | 区域经营开场、地理临场感 |
| 02 | **地形等高线 / Relief** | 独立的程序化晕渲/等高线纹理；国家材质偏地形图 | 等高线脉冲、选中国家地形夸张高度 | 宏观区域经营分布、研究感 |
| 03 | **杂志制图 / Editorial** | 象牙色纸质顶面、排线、双描边和注释指示 | 地理注释引线、轻微抬升 | 正式汇报、结论叙事 |
| 04 | **低多边形卡通 / Low Poly** | 多边形色块拼贴、粗边界、面片深浅分阶、明显侧壁 | 弹性抬升/高度动作 | 强记忆点的展演开场 |
| 05 | **玻璃叠层 / Glass** | 透明国家顶面、半透明侧壁、可视内部坐标网格、双层悬浮玻璃面 | 图层分离与合拢 | 将国家连接到渠道结构与机制盘 |
| 06 | **技术线框 / Wireframe** | 几乎无顶面填充，国家以网格线、骨架边、侧壁几何表达 | 扫描束、网格密度变化 | 结构剖析、工程/治理汇报 |

## 三、交互和业务数据的共同契约

**共同能力**：点击/快速选择国别、国别指标卡联动、目标达成/铺货/上样/WOS着色、国家旋转与缩放、俯瞰/低空镜头、轮廓线强度调节、各模式的独立图层动作、键盘1–6切换、全屏。页面始终保持同一套暗色侧栏与数据卡，避免把外部UI改动误判为“地图设计差异”。

**业务边界**：销售额、目标等是合成的静态阶段快照。WOS只作为演示指标，其“越低越好”判色不是可用于所有业务情境的标准；不同国家、产品与渠道需要阈值和趋势背景。六种渲染画风**没有被直接接入真实经营数据，也没有新增机制推演功能**。

## 四、验收与下一步

- **程序验证**：浏览器在1600×900运行六套样式；逐项切换返回正确标题，国别按钮由泰国切越南同步刷新销售数据，图层按钮、WOS着色开关均能触发，浏览器无JavaScript运行错误。地图几何、嵌入纹理文件均在同一HTML，不要求联网。
- **视觉验证**：六种地图顶面明显不同：两种纹理贴图、纸本排线、卡通三角面片、半透明双层、透明线框网格；侧壁和边界采用不同语法，而不是只是不同基色。预览图在本次会话中生成，**未假定PNG已进GitHub**。
- **演进方向**：若要“真正的卫星视图/真实地形视图”，需要符合许可要求的正射影像瓦片、DEM高程、投影配准、级别细节与离线缓存方案；当前不能将合成纹理对外宣称为真实卫星或地形数据。
- **融合建议**：地图本体可以按展示阶段混用不同**图层语法**——例如卫星/地形做全貌底图，杂志注释做结论层，玻璃爆炸与线框拓扑做经营机制展开。但要确保一个界面里叙事逻辑连贯且性能可接受，不应六种素材同时叠满画面。
- **优先级**：继续遵循 [综合-渠道经营机制沙盘与跨模块推演设计](channel-business-mechanism-workbench.md) 的 P0业务计算正确→P1交互一致→P2推演可信→P3视觉审美。
