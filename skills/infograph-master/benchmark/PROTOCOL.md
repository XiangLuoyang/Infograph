# Benchmark protocol
Use synthetic fixtures only. Compare baseline no skill, V1.0 pinned commit, and V1.1 pinned commit with same model/version, reasoning setting, task, data, tools, time and output constraints. Randomize run order; use fresh contexts; at least three repetitions per arm for exploratory comparison, not statistical proof. Blind human reviewers to arm; record rubric applicability before runs, preserve failures and raw artifacts. Report per-task scores, hard failures, median/range, time and tokens when observable. Separate engineering checks from human ratings; missing ratings remain not-run. Do not aggregate unlike task sets or claim superiority from this protocol alone. For comprehension use independent readers and counterbalance order. Score rubric is provisional, not calibrated. No model benchmark executed yet.
