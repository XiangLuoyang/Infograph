# Local pilot runner (Node 22)
Run from benchmark directory: `node run-pilot.mjs --limit 2` (dry run). Set BENCH_BASE_URL to your provider's HTTPS API base including version prefix, BENCH_MODEL to exact model ID, BENCH_API_KEY via secure environment. Then `node run-pilot.mjs --execute --limit 2 --out benchmark-local`. Same output directory resumes by skipping existing run directories; inspect incomplete directories manually. Default one request, sequential, stop on failure, no retries. Fixed temperature 0.2 and max_tokens 8192 are provisional; provider compatibility unverified. Use separate output directories for different models. Do not open untrusted generated HTML outside a sandbox; do not commit raw outputs or secrets automatically. HTML extraction is structural only, not quality or security validation. No actual API calls or native execution performed. Full means C09-C inline subset, not modular ablation. Raw responses may contain sensitive content; use synthetic fixtures only.
