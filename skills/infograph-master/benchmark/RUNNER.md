# Local pilot runner (Node 22)
Run from benchmark directory: `node run-pilot.mjs --limit 2` (dry run). Set BENCH_BASE_URL to provider HTTPS API base including version prefix, BENCH_MODEL to exact model ID, BENCH_API_KEY via secure environment. With explicit spending authorization run `node run-pilot.mjs --execute --limit 2 --out benchmark-local`. Default one request, sequential, stop on failure, no retries. Temperature 0.2 and max_tokens 8192 are provisional; provider compatibility unverified.
Resume validates existing record identity, prompt hash and saved prompt, model/settings and completed HTML hash before skipping. Failed records are retained; incomplete or inconsistent directories require manual investigation, not silent retry. Use separate output directories for different models. Resume does not authenticate provider identity or raw response provenance.
Use synthetic fixtures only. Do not open untrusted generated HTML outside a sandbox; do not commit raw outputs or secrets automatically. HTML extraction is structural only. Full means C09-C inline subset, not modular ablation.
Native synthetic smoke tests have passed in CI (run 45569034658); zero real model requests are evidenced. Dry-run and mock success do not establish provider compatibility or effectiveness.
