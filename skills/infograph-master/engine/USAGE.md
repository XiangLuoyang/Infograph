# V1.1 increment usage
Read styles.json, layouts.json, materials.css, motion.css and chart-rules.json after the master workflow. Select assets explicitly; use engine.route(task,fields) for candidate screening, never as proof of domain suitability. Write design JSON following design.example.json. Run python engine.py design.json and python -m unittest test_engine.py from this directory. These tests are supplied but have not been executed in this repository. Structural checks cannot establish truth or aesthetics. No browser validation. V1.0 remains unchanged.
## Compiler increment
Run `python compiler.py design.example.json` to generate scene plans. Optional scene blocks have id, role and weight (1–10); fields supplies chart router inputs. Bind scene and evidence IDs to actual HTML, use .ig-grid and data-ig-block with --span-desktop and --span-tablet from the plan. Load compiler.css. Load visual-check.js and run infographVisualCheck() at each target viewport and interaction state; inspect all warnings manually. Only tagged visible blocks are checked. Run `python -m unittest test_engine test_compiler`. Tests not yet executed. This is a heuristic span planner, not a complete renderer or semantic narrative compiler.
