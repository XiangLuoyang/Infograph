# Art direction candidates
20 semantic direction presets, not 20 finished design systems. Each maps typography, composition, material, preferred chart language and motion. Chart preference never overrides data semantics. Use typography-composition.css with .ig-type-{type}, .ig-composition[data-mode], .ig-title, .ig-body, .ig-note, .ig-number. Choose compatible existing style tokens and material CSS. Spatial/hero presets only reserve space, not map or camera implementations. Timeline is a vertical rule, not a time scale. Compare actual rendered designs before selecting. No font files bundled; fallback availability varies. No browser or user testing yet.
