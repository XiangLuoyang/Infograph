# Specialist increment
Material catalog: 20 CSS recipes, not physically based shaders. Extended recipes set foreground; verify accent, transparency and actual contrast. Chart transforms return data, not rendered charts: waterfall requires additive contributions; histogram counts observations; attainment requires positive target. Spatial transforms use abstract Cartesian coordinates, not geographic projection. Explode requires supplied part positions and offsets; no inferred geometry or assembly order. Use domain renderers for real maps, CAD, medical and scientific geometry. Do not imply physical accuracy. Tests and browser verification must be recorded separately.
