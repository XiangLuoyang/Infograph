# Artifact inspection & semantic IR (P0.2)
This increment adds a bounded, local static HTML inventory and comparison tool. It does not infer business intent automatically, run artifact code, validate actual chart data, or reconstruct the visual design.

## Workflow
1. In an environment with the repository's Playwright/Chromium QA dependencies installed, run `node engine/artifact-inspector-cli.mjs existing.html > original.ir.json` from skill root. Parse in inert DOMParser in a blank offline browser, do not navigate to the input or evaluate its scripts. 8 MiB input limit; bounded observations, text and table cells; truncated coverage stays partial. Keep output local: static markup and JSON may contain confidential values.
2. Inspect the actual rendered artifact separately in a trusted, authorized environment and record screenshots/state tasks; static extraction cannot see runtime canvas/chart data, computed layout, event effects, network data, formulas or hidden dynamic views. Source only is limited.
3. Review observations and author an intent graph using buildIntentGraph (intents, evidence links, explicit/inferred/unknown, alternative + validation for inferred). Link supports/context/contradicts/unknown to actual observation IDs. Infer business needs and diagnose L5–L1 as described in reverse-design-reconstruction.md. Do not equate observation with requirement.
4. Populate the reconstruction contract using source refs. Give important elements unique stable data-semantic-id or id in a revised artifact; do not assume original labels identify same data. Compare explicit IDs or author-reviewed aliases using `node engine/artifact-diff-cli.mjs original.ir.json revised.ir.json [aliases.json]`. Static equal means exact observed fields only, not data parity, computed behavior or semantic equivalence. Unkeyed, ambiguous, changed, missing and truncated observations require review. Keep original values, formulas, states and user tasks separately verified.

## Observation types and limits
Headings, regions, paragraphs/list/definition text, tables (cell spans and raw strings), native/role controls (labels and select defaults/options), SVG/canvas/role image identifiers and title/description, JSON script blocks (bounded parse), script existence/length and fragment link evidence. Arbitrary div text, external data, JS arrays/formulas, responsive styles, live values and event graphs are not automatically extracted. Source hash and structural selector locate the observation; no original byte offsets. No secret scanning guarantee; do not publish snapshots. Explicit semantic IDs or HTML IDs are only candidate matches; duplicated IDs are ambiguous. Incomplete extraction cannot certify absence.

## Status
Pure IR/diff/graph test covers changed/missing/ambiguous observations, traceability and alias behavior. Browser fixture is integrated into existing Playwright CI. The real-world extraction quality, live runtime inspector, inference accuracy and comparison to cosmetic-only baseline are separate pending work. No release approval.
