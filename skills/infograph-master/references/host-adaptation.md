# Host adaptation V0.1
Select capabilities by actual session, not model brand. Repository mode requires access to referenced files; reader mode can inspect but not execute; inline mode embeds five core documents, not the full specialist library; browser profile adds observed browser QA. All preserve evidence, task-specific narrative, design and acceptance constraints. Use engine/skill-package.mjs packageSkill with source assets containing path, SHA, bytes and content. Example is a snapshot, not a live bundle; refresh on source changes. No native vendor installation, token measurement or cross-model adherence claim. If required knowledge/tools unavailable, disclose and narrow scope. Never mark unrun tests pass.

## Execution architecture host contract (P4a)
- Repository/verifiedBrowser: run preflight and start-workflow; use status/task/run, bind actual HTML, run trusted browser review and critique; before candidate handoff require delivery-check and verify-handoff.
- Browser explicitly blocked: disclose actual error and obtain user agreement before preparing unverified-draft; preserve the UNVERIFIED DRAFT label. An observed browser failure must be repaired, not downgraded. Browser not run is not blocked evidence.
- Reader/inline or no shell: manual assistance only; report unavailable capabilities and unexecuted stages. No verified candidate or fabricated receipt.
- OpenClaw integration contract: the operator, not the model, owns a trusted verifier and file-sending wrapper. Pass run directory and exact candidate file to prepare-handoff, verify-handoff immediately before transmission; send only exact verified HTML bytes with classification and limitations, after normal destination authorization. Refuse missing or failed verification and raw direct HTML sends for Infograph tasks. Protect the workflow/verifier and evidence paths under host controls; local hashes do not defend against an actor able to rewrite every record. No real OpenClaw hook, permission change, or sender interception is installed by this repository. Validate with a held-out host trial and deliberate direct-send attempts before claiming enforcement.
