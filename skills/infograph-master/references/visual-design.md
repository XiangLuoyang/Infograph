# Visual design execution rules
## Color
Define canvas, surface, text, muted, border, accent, positive, negative, warning, neutral and categorical/sequential/diverging scales. Use consistent semantic mappings and redundant labels/icons; color alone must not convey status. Aim for WCAG AA text contrast (4.5:1 normal, 3:1 large) and relevant non-text contrast. Example editorial palette: canvas #F5F3EE, surface #FFFFFF, text #202A28, muted #52615D, accent #285B4D, warning #946000, negative #A33C32. Alternative industrial dark: canvas #15201F, surface #22302E, text #F1F4F2, accent #9AC9B8. These are starting tokens, not audited palettes; test actual pairs. Do not assume cultural color meanings are universal.
## Typography
Choose a coherent sans or editorial serif/sans pairing, with CJK fallback and tabular numerals. Example desktop scale 12/14/16/22/32/48px, adjust for projection and density. Use line-height around 1.4–1.6 for prose, align numeric columns, show units, avoid tiny labels and all-caps Chinese headings. No unlicensed font redistribution.
## Layout
Select Matrix (monitoring/comparison), Editorial (claim/evidence), Hierarchical (overview/detail), Flow (sequence), Spatial (geographic/physical). Compose around one dominant task per scene. Use 4/8px spacing rhythm, aligned baselines, deliberate asymmetry, sufficient whitespace, direct chart annotations, adjacent evidence. Avoid equal cards by default; use tables for dense lookup. Responsive order must preserve meaning; test 390, 1440, 1920px widths.
## Material
Matte paper for editorial evidence; glass for contextual overlays with opaque fallback; parchment for historical/archive context; metal/instrument for industrial interfaces; terrain/solid volumes for spatial structure; wireframe for topology. Define role, opacity, texture, shadow and contrast per layer. Never obscure labels with blur, texture, specular effects or perspective. Material associations are design hypotheses, not universal psychology.
## Chart selection
Ranking: sorted bar/dot; target deviation: diverging bar/bullet; time: line/small multiples; composition: stacked bar/treemap; distribution: histogram/box/ECDF; relationship: scatter; contribution: waterfall only for additive quantities; flow: Sankey only with reconciled flows; geography: choropleth for normalized rates, proportional symbols for totals; precise lookup: table. For engineering, architecture, science and networks consult domain routing and catalog. Separate canonical type from projection, material and animation. Avoid 3D distortion of quantitative comparisons, misleading axes, fabricated uncertainty or causal claims.
## Diagrams and space
Model nodes, edges, ports, groups and direction before layout. Use orthogonal routing or ELK when appropriate, minimize crossings without altering topology, preserve labels and swimlane semantics. Maps need grounded geometry, projection, legend and scale when relevant; simplified geometry must be labeled. 3D requires a genuine spatial task or clear illustrative purpose, not decorative extrusion alone. Never imply engineering-standard accuracy without verification.
## Motion and interaction
Define trigger, state, affected IDs, transition, duration, easing, interrupt/reset, keyboard/touch fallback. Suggested durations 120–250ms micro, 250–500ms scene, longer only for explanatory sequence; not mandatory. Maintain object constancy, preserve filters and selection, provide static/reduced-motion alternative. Use progressive disclosure, linked highlighting, drilldown, scenario presets, source inspection; essential evidence visible without hover. Model inputs must have bounds, units and assumptions. Avoid perpetual decorative animation.
## Visual specification
Record chosen art direction, rejected alternatives, token values, typography scale, layout per scene, chart encoding and rejected alternative, material roles, interaction state map, responsive strategy, and dependencies. Reference actual repo examples when relevant rather than copying a generic dashboard.
