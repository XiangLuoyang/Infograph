# Color Studio
Serve the full repository via HTTP, e.g. from visual-intelligence run `python -m http.server 8000`, then open `http://localhost:8000/color-studio.html`. ES modules and JSON fetch require HTTP. 20 preset parameter seeds, 13 case links, live art palette, semantic scale, simulated vision, single backdrop compositing, contrast audit and JSON export. Presets are regenerated as art palettes, not exact reproduction of stored tokens. Ranking/category/magnitude/deviation/status previews use synthetic data. Status remains unknown absent thresholds. Audit is normal-text contrast, not certification. JS syntax checked; browser execution and export not tested. Invalid input disables export but may leave previous preview visible. No external runtime dependency.
