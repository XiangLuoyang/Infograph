# Composition Studio
Serve repository root via python -m http.server 8000 and open skills/infograph-master/visual-intelligence/composition-studio.html. Imports existing semantic, attention and rectangular solver modules. Atlas browses catalog records; semantic relation examples are independent synthetic objects, not claims about the preview metrics. Geometry templates are manually selected, not automatically compiled from archetypes. Two visual modifiers and selectable emphasis; export includes geometry and declared attention. No browser, export, text-fit or audience validation. JS syntax checked after removing import declarations. This is an integration prototype, not a complete visual editor.
