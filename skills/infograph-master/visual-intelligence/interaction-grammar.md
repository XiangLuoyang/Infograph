# Interaction grammar
Twelve candidate semantic primitives: select, focus, filter, drill-down, roll-up, compare, link, trace, navigate, manipulate, simulate, restore. Runtime implements selection, focus, filter, drill, rollup, peer comparison, navigation, bounded parameter, undo and reset. Link, trace and simulation are not implemented. Filter null means unrestricted; empty array means no matches. Scope and selection are independent; consumers must explicitly define cross-view policy. Undo stores snapshots without history limit. Configuration assumed immutable and JSON-compatible. No DOM, persistence, evidence validation, accessibility or browser testing. Seventeen inline checks passed after replacing unavailable structuredClone with JSON cloning. Candidate taxonomy, not empirically validated.
