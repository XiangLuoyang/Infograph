# Motion Studio
Standalone HTML bundles snapshots of six existing modules and the engine example. Open locally without a server. Market selection, filtering, chapter navigation, conditional supply scenario, undo/reset, reduced motion, revision-aware FLIP cancellation, JSON export. Two synthetic markets. Disclosure displays IDs rather than authored narrative. No focus control or multilevel drill. Syntax checked via Function constructor; no browser execution or export verification. Bundled snapshots require rebuild after module changes. OS reduced-motion preference overrides animation.
