# Multilingual typography
Source reviewed: W3C Chinese Layout Requirements https://www.w3.org/TR/clreq/ sections 6.1–6.2. Preserve punctuation conventions by locale; avoid splitting signed numbers/currency and paired punctuation; Chinese-Western spacing is contextual, not blanket tracking. Use explicit language runs and atomic spans for short quantities/identifiers. Never rewrite source text automatically. Chinese book justification does not imply dashboard justification. Locale candidates cover zh-CN, zh-TW, zh-HK, en, vi, th, km, my, ms; non-Chinese scripts are provisional engineering defaults, not independently researched language standards. Thai/Khmer/Myanmar need native shaping and segmentation; no manual word splitting. CSS text-autospace is progressive enhancement. Atomic spans can overflow narrow containers; allow more width or an alternate layout. auditLines checks supplied line strings only, not DOM wrapping or complete Unicode line-break rules. No fonts bundled, no browser or native-reader validation.
