# Numeric and financial typography
Separate raw values, scale, units, locale, precision and semantic direction. Percent input is a fraction; percentage points are a distinct number/unit contract. Null is unknown, not zero. Use common scale and precision for comparison columns; never hide material changes through rounding. Currency uses Intl.NumberFormat with explicit currency code; scaled currencies require number/unit contract. No FX conversion. Decimal parts support localized separators and sign placement; cross-row decimal alignment requires shared column tracks, not independent row grids. CSS provides right alignment and tabular figures where supported. Use proportional display figures for expressive KPI where appropriate. Reserve stable width for live numbers; avoid animated intermediate values that imply measured observations. Negative does not imply adverse. Financial table hierarchy: group headers, subtotals, totals, units and source notes. No accounting rounding or exact decimal arithmetic; JS Number is binary floating point.
