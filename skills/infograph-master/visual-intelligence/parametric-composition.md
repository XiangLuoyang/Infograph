# Parametric composition
Deterministic recursive rectangular split solver. Each child receives its minimum plus a weighted share of remaining axis length. Cross-axis minimum is checked recursively. Global narrow viewport stacks groups unless opted out. Input order is preserved. Infeasible constraints throw rather than clip. This is not a general constraint optimizer: no text measurement, intrinsic height, max bounds, overlap, freeform, radial or geographic geometry; nested minima are not propagated upward, so feasible alternative allocations can be rejected. Fixed canvas height must be supplied by caller. Eleven inline checks passed; no browser validation. Weight is allocation preference, not measured visual salience.
