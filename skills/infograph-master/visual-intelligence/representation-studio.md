# Representation Studio
Serve directory over HTTP (python -m http.server 8000), open representation-studio.html in a modern browser supporting JSON import attributes. Imports the actual index, selector and SVG adapter; studioRun gates rendering on declared inputs, catches invalid data, and preserves unsupported status. Catalog search, task selection, editable JSON, audit and SVG export. Six inline integration checks using fetched module sources; UI script syntax checked after stripping imports. No browser execution, actual export test, or ES module loading test. Only three narrow native renderers. No automatic visual quality audit. This completes planned V1.2 basic rounds, not production readiness.
