# Specialist adapter prototype
Three native SVG adapters: horizontal nonnegative bar, chronological nonnegative line, directed binary adjacency matrix. Unsupported IDs/backends return explicit unsupported, never substitute. Invalid data throws. Input constraints deliberately narrow. SVG text escaped; summary included in desc. No external renderer installed. No browser visual audit; labels may overlap or clip, unit is in description not visible axis, matrix direction is in description. No selector integration or semantic fallback execution yet. Twelve inline assertions passed; standalone test not executed. Future adapters: ECharts/Vega-Lite statistical, D3 networks, deck.gl maps, Three.js geometry, VTK.js scientific, Mol* molecular. These are planned only.
