# Typographic space and rhythm
Use proximity to group related information; separate changes of topic more strongly than related labels. Candidate spacing hierarchy: inline, related, paragraph, section, chapter. Snap line height and spacing to a small grid where practical; actual glyph baselines depend on font metrics, mixed fonts and browser layout. Never claim baseline alignment from line-height alone. Use asymmetric composition only with clear reading order; align to shared anchors and retain whitespace around focal claims. Reading measures 65ch English and 36em Chinese are starting heuristics, not actual character counts or standards. Dense tables require separate spacing rules. Avoid fixed heights that clip enlarged text. Review at narrow widths, 200% zoom and user text-spacing overrides.
