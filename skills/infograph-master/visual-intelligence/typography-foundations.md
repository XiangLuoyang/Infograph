# Typography foundations V1.2
Typography is information hierarchy, not font decoration. Establish semantic roles before styling: display, heading, subheading, body, label, note, metric. Use size, weight, spacing, alignment and position before adding color. Do not force every role onto every page.
Three initial directions: editorial (serif headings, sans body), Swiss-inspired (sans hierarchy, grid), technical (compact sans, aligned numbers). These are candidate recipes, not historical reproductions. Font stacks are fallbacks, not bundled fonts; actual availability and CJK glyph coverage vary.
Numbers: use tabular lining figures for comparable columns if supported; align values by consistent units/precision, show minus signs and missing values explicitly; do not round away material differences. Large display metrics can use proportional figures. Decimal alignment needs layout support, not merely tabular figures.
Chinese/mixed: preserve punctuation and language-specific line breaking, avoid blanket letter spacing, avoid forced breaks inside Latin words and units where feasible; use lang attributes for language runs. 36em Chinese and 65ch English are starting measure heuristics, not accessibility requirements. CSS overflow-wrap anywhere is emergency wrapping. Test long labels, zoom, font fallback and narrow screens.
Reference reading queue (not freshly retrieved): https://www.w3.org/TR/clreq/ ; https://www.w3.org/TR/css-text-3/ ; https://www.w3.org/TR/css-fonts-4/ ; https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html ; Robert Bringhurst, The Elements of Typographic Style; Josef Müller-Brockmann, Grid Systems in Graphic Design.
The module generates candidate tokens and CSS. It does not measure glyphs, enforce actual line length, guarantee font features or certify accessibility.
