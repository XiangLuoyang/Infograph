# VMI V0.1 — research and executable retrieval seed
Candidate, not mature. Use after visual opportunity discovery when a mechanism could improve comprehension. Do not force metaphors for exact lookup or unsupported claims. Preserve a conventional evidence alternative.
1. Author target graph independent of physical objects: decision, entities, directed predicates, essential edges, source evidence, observed vs hypothetical status. Consider distinct abstractions for complex tasks. See ontology/mechanisms.json. Do not confuse a graph with verified causality.
2. Retrieve via engine/analogy.mjs rankCandidates(target,objects,ontology); exact predicate recall then bounded injective directed edge alignment. Inspect unmapped edges, essential coverage, truncated searches, source and limits. A score is only structural coverage, not creative merit. If no appropriate candidate, explicitly search other domains using functions/relations, verify physical mechanism against sources, author new graph locally and rerun. Do not assume library completeness; compare at least two semantically distinct candidates and a non-metaphorical alternative. Never manufacture a mapping to fill a quota.
3. Develop candidate scene concepts; compare physical mechanism fidelity, cognitive effort, visual potential, design DNA, interaction and feasibility. Author limits and counterexamples. Use critiqueMapping as a declared hard gate, not autonomous reviewer. Reject false causality, false measured geometry, or missing essential relations; revise or use ordinary diagram.
4. Inherit existing palette, typography, material, lighting, composition and state grammar. Use existing DP01–DP05, dynamic-visual-metaphor.md and reference-reconstruction.md when appropriate; choose image assets only when task supports them. Keep labels and data layers editable and qualitative geometry explicitly marked. No automatic scene compiler exists yet.
5. Render, inspect desktop/mobile and reduced-motion states, verify mapping and exact evidence; ask independent readers to reconstruct intended meaning in future benchmarks. Do not call self-review comprehension validation.
Run node tests/analogy.test.mjs from this directory. Benchmark fixture is synthetic and only checks mechanics, not real model creativity.
