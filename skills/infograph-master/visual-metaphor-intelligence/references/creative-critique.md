# P3 creative exploration and critic
This is an authored concept workflow, not a generative image algorithm. Read after P2. The target graph, evidence, source selection and proposed imagery are written by the agent; code checks declared constraints and proposes bounded creative routes.

## Creative operators
- Direct: retain a single real mechanism; make its functional structure visible.
- Combine: complementary source relationships become one explicitly schematic scene; never claim that the resulting hybrid is a real functioning object. Preserve separate source anchors and no invented bridging physics. If coupling itself matters, add evidence or use a plain diagram.
- Juxtapose: contrast or complement mechanisms in separate panels; preserve target identity with explicit correspondence labels when objects recur.
- Substitute: change a visual form while retaining source function and label the abstraction boundary; a replacement object is not automatically physically equivalent.
- Transform: stable objects and meaningful, reversible or static-representable state transitions with evidence status; P3 prohibits quantitative motion and geometry rather than pretend calibration. Ordinary quantitative evidence belongs in separate plots.
Consider genuinely different routes, not just surface recoloring. Compare with ordinary evidence. Prefer no metaphor if it has higher clarity. No novelty quota.

## Workflow and data contract
1. For each target perspective run P2 alignPerspective then enumerateCreativeRoutes. Routes are prompts for authorship, not concepts or recommendations; inspect partial coverage and open-discovery requirements. Search beyond top seeds if needed.
2. Author concept JSON (benchmark/creative-fixture.json is synthetic example): revision, targetId, operation, intent, focalScene, plainAlternative, boundary, designDNARef, evidenceRef/kind, sourceIds, panels, sceneObjects (stable ID, panelId, targetNode, source anchors), bindings (target edge, source edge, endpoint objects, interpretation and qualifier review), qualitative flags, counterexamples. Add operation-specific fields as required. Preserve target evidence status. Map every essential relation. Source anchors must exist in actual source graphs; role, condition, polarity and direction recomputed. Source-only qualifiers are flagged as well as target unknowns and generalizations. No arbitrary invented source relations. Unmapped optional edges must not be silently asserted in a scene.
3. Run auditConcept on actual target/corpus; resolve findings or reject. Counterexamples must be concrete scenarios, failure and mitigation with a reference. Include at least one adverse condition that challenges the mapping; e.g. lack of external intervention, non-exclusive capacity, shared failure mode. A declared mitigation is not independently verified.
4. Compare candidates using compareConcepts. Rating dimensions semantic fidelity 30, comprehension 20, visual potential 15, style fit 10, interaction 10, originality 10, feasibility 5. Ordinal 1–5 and rationale per dimension; weights provisional. Hard gates override rating, including false causality, quantitative deception, missing sources, unresolved counterexamples, excessive explanation, style conflict, stale review. Distinguish self-review and independent reviewer. Do not use score as proof of actual understanding. Two eligible candidates are a useful comparison when possible, not a requirement to force bad metaphors; if insufficient, record why, continue discovery or choose plain evidence.
5. Author selection rationale and rejected alternatives, then follow DP01–DP05, design DNA and dynamic visual metaphor acceptance. P4 will provide scene IR/style integration; P3 does not render. Independent reverse-comprehension and rendered scene tests remain not-run until actual artifacts and readers exist.

## Limits
No automatic language abstraction, physical simulation, source authenticity check, image generation, aesthetic evaluation, or independent evidence verification. Inputs are untrusted authored declarations. Source graph/target graph validation is bounded; qualitative mapping does not prove causality. Scores are advisory only. No automatic release.
