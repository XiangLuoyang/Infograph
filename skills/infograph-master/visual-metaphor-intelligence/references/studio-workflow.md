# P5 Studio and renderer handoff
Run node engine/studio-build.mjs studio-local.html from VMI root, then open output in a browser. studio/visual-metaphor-studio.html is the checked-in standalone output. Edit JSON for authored perspectives, concepts, review, style and scene; run retrieval and review, preview eligible supported SVG/HTML scenes, export packet or independent scene, and reset. A fresh arbitrary prompt still needs Agent authorship: this is not a natural-language model or external source search service. Data is processed locally in the browser; no arbitrary code input. Imported JSON is not automatically trusted, and all review declarations need real verification.
Pipeline evaluatePacket wraps the P2/P3/P4 real engines; incomplete inputs block rendering without fabricating concepts or reviews. Open discovery is a warning to perform actual source discovery before selection, not satisfied by demo. Studio displays scores as declared and source links as text. Synthetic example demonstrates one concept; it is not an independent assessment.
Advanced renderers: engine/handoff.mjs calls the existing ../../engine/reference-scene.mjs compileReference on an explicit per-object requirement manifest. Stable semantic ID maps accompany renderer slots, and missing required backends block planning. Raster/photoreal requirements need an asset plan. The bridge does not render or transfer actual scene primitives, generate assets, create arbitrary WebGL geometry or implement mobile reference layout. Association ports are placeholders: before using buildReferenceHTML, author approved assets/geometry, meaningful directional connectors, state behaviors and actual responsive composition; follow reference-reconstruction.md and actual fidelity review. Do not claim equivalent fidelity merely because all slots are assigned. Keep SVG as fallback only when explicitly justified and clearly disclosed.
See benchmark/PROTOCOL.md in this subdirectory for prospective evaluation. Real browser/visual checks and independent task runs remain pending.
