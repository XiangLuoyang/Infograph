# Validation protocol
Compare baseline module dashboard with skill-generated narrative using identical data, audience task, styling, available evidence and time budget. Randomize assignment or counterbalance order with equivalent datasets to limit learning. Record participant count, task order, device and exclusions. Measure 30-second thesis recall, lookup accuracy/time, mechanism explanation, evidence retrieval, decision justification, 1–7 subjective difficulty and delayed recall. Score against predefined answer key; report individual results and uncertainty, not fabricated scores. Separate interface defects from narrative defects. Audit factual claims, omitted counterevidence, formulas, units, keyboard access, reduced motion, viewport overflow and export consistency. Hard fail on unsupported causal claims, incorrect numbers or hidden material caveats. No actual audience testing is included in V1.0.
