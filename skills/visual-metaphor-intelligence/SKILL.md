## Independent manual mode
If the host copies only this Skill, use the following complete compact workflow without claiming engine execution. Missing references/renderer capabilities must be disclosed.
1. **Abstract the mechanism**: state the reader task, decision, entities, directed relationships, conditions and polarity. Distinguish observations, hypotheses, assumptions and decisions; attach evidence IDs, scope and limitations. Identify indispensable edges and unknowns. No analogy is evidence by itself.
2. **Open-domain discovery**: describe the mechanism in several abstractions (constraint, distribution, feedback, transition, network, trade-off as appropriate). Search conceptually across natural, engineered, biological, architectural, social and other domains; do not limit candidates to a factory metaphor or fixed list. Verify unfamiliar physical behavior using reliable sources when necessary. Compare at least two substantially different metaphor mechanisms and one plain representation. Reject candidates with material false mappings, hidden conditions, implied quantitative magnitude or unsupported causality.
3. **Creative critique**: explore direct analogy, substitution, combination, juxtaposition or transformation only as justified. For each candidate map target entity/edge -> source object/relation -> intended interpretation -> evidence status -> analogy limit. Score qualitatively by semantic fidelity, expressive power, feasibility, style coherence and evidence risk; hard failures override preference. Choose a direction with rationale, or choose the plain alternative.
4. **Art direction**: specify dominant silhouette, camera/view, relative scales, composition, palette, materials, lighting, typography/label safe zones. If suitable and authorized, produce and inspect concept artwork; otherwise sketch or state the fidelity limit. Keep data and labels independently editable. Never bake exact metrics into the picture. Define stable object IDs, visual roles, bounds, depth, ports, mask/clean-plate requirements, and per-layer renderer. Distinguish inferred geometry from observed appearance. Preserve existing design DNA.
5. **Interactive scene**: author endpoint states, visible objects, focus, semantic labels, exact evidence, meaningful triggers, state transitions and inspection independent from narrative. Map only calibrated quantities to geometric magnitudes; otherwise label illustration qualitative. Inventory physically salient objects, consider rigid, articulated, deformable, liquid, gas and optical behavior; justify static parts and choose motion based on task. Define pause, interruption, reverse and reduced-motion behavior. Ensure every essential fact is available without animation. Choose renderer appropriate to fidelity; disclose unsupported implementation rather than silently substituting.
6. **Render and review**: deliver the requested artifact if tools allow; compare the actual output with the concept and conventional evidence; inspect material, perspective, occlusion, motion, text legibility, controls, responsive reading and exact data. Record actual checks separately from planned ones. Preserve approved layers. Do not claim independent comprehension, aesthetic approval or model improvement from structural checks.

Deliverables (compact for small tasks): mechanism/evidence ledger, distinct alternatives, selected concept and limits, stable scene mapping, art/asset and interaction plan when needed, actual output and revision-bound review. When only manual mode is available, state that the canonical engine was not run.
